# Word Counter Java

I designed a Java application that reads a text file and counts the most frequently used words.

## Technologies

- Java
- Java Collections Framework
- HashMap
- Stream API
- File I/O


## How It Works

The application reads a text file and counts the frequency of each word. Then the results are sorted from the most frequently used word to the least frequently used ones.

For example:

The output after the application reads the `poem.txt` file should look similar to the following:

*** SORTED BY MOST FREQUENTLY USED WORD

Word: the   | Frequency: x times
Word: and   | Frequency: x times
Word: of    | Frequency: x times

## How to Run

1. Clone the repository.
2. Open the project using a Java IDE.
3. Update the file path in the `CountProject.java` file.
4. Run the `CountProject` class.
